🎮 How to Play

Player 1 uses X.

Player 2 uses O.

Players take turns selecting an empty cell.

The first player to get three symbols in a row wins.

A row can be:

Horizontal

Vertical

Diagonal

If all cells are filled and nobody gets three in a row, the game ends in a draw.
